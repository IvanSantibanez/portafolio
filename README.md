# Prototipo Panel de Seguros VFMG

## Descripción

Prototipo desarrollado como apoyo al proyecto de portafolio para el Instituto San Sebastian.

El proyecto presenta una propuesta visual para el panel de gestión de seguros utilizado dentro del módulo de refinanciamiento VFMG, permitiendo visualizar y administrar los seguros asociados al proceso de refinanciamiento.

## Objetivo

Mejorar la experiencia de usuario y la organización visual de la información dentro del flujo de refinanciamiento.

## Tecnologías utilizadas

* HTML
* JavaScript
* Tailwind CSS

## Alcance

Este repositorio contiene únicamente una propuesta visual y no incluye código ni información sensible a sistemas internos de la organización.
